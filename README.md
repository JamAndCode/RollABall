RollABall

This is a traditional, 3D game made with the Unity game engine as an introductory project during a game-development
class. The goal was to follow the Unity RollABall tutorial [https://learn.unity.com/project/roll-a-ball] and extend it 
to make it our own.

I experimented with user functionality by implementing multiple user interactions which change the game board, including
sliders, radio buttons, and user inputs to determine what populates on the game board. There are also user controls
presented during gameplay, which disappear after a short time.

This is a 2-player 1-keyboard game, with an optional enemy spawn. To complete the game, all collectables must be collected
by either player, at which point the player with the highest score will be named the winner.
